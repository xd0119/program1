体验游戏生成智能体 体验游戏
STAR · 项目故事
S
独立开发一款推理 RPG 耗时 1 周、累计消耗 1800 万 token，期间经历各种 AI Coding的bug：AI 生图渲染不稳定、AI 生成代码出现递归中断与数值失衡。搭建智能体把踩坑经验固化成可复用的生产流程。
T
目标不是"再做一个游戏"，而是沉淀一套可复用的 AI 内容生产引擎，实现"输入剧本需求 → 端到端输出可运行 HTML"，验收标准为：产出质量可控、生成成本可控。
A
①识别 AI边界 跑通全链路：用 AI 生图+写代码产出 RPG 游戏 V1，发现 AI 渲染中文（结构性缺陷→改用 CSS 渲染文档）、代码递归中断、数值失衡等问题 → 逐个根因修复。沉淀为后续校验层的约束规则。
②架构解耦，为自动化铺路：将剧情数据与渲染层分离，剧本独立为结构化数据，改剧情不动 HTML。
③搭建Coze 智能体生产引擎：
架构设计：拆解为 4 个单职责工作流（搭建框架/改剧情/AI生图/用户传图）挂载于同一智能体，通过 Bot 级变量实现跨工作流状态共享与接力编辑。
校验设计：编写确定性校验层将 LLM 幻觉拦截在渲染前——契约校验、引用完整性、闭环可达性。
成本与交付稳定性：按任务复杂度为各节点分档选型；素材以固定对象存储 key 覆盖更新，保证多轮编辑后交付链接不变。
R
交付「RPG 游戏生成」智能体，用户输入题材 → 产出可玩 HTML。
质量可控：设计4 类确定性拦截规则，覆盖 LLM 幻觉的主要失效模式（剧情不自洽/选项死循环/素材丢失/结构非法）将 LLM 幻觉拦截在渲染前。
成本可控：按任务复杂度对 LLM 节点分档选型（关键节点 Pro / 机械提取 Mini），配合模板引擎渲染将渲染 token 归零。

网站概述

本网站是许晓丹的个人作品集，展示完整项目经历，涵盖AI智能体、Web开发、AICoding小程序、workflow编排、VR交互设计等领域。整体设计采用莫兰迪暖色系，支持主题色切换。搭载智谱+本地AI做项目问答助手，同时引入访问统计。

技术架构

纯静态 · 纯前端
基于 HTML + CSS + JavaScript 构建，前端托管于 GitHub Pages，无需服务器和数据库，零运维成本。所有交互（AI对话、主题切换、动画）均在前端完成。
Tailwind CSS · 原生JS
使用 Tailwind CSS 提供原子化样式，配合自定义 CSS 变量实现主题切换。所有交互逻辑使用原生 JavaScript，无框架依赖。
零成本安全代理 · Cloudflare Pages
API Key 不写进前端，而是部署一份 Cloudflare 做 Serverless 中转： Key 以 Encrypt 加密环境变量 形式只存在 Cloudflare 后台，前端一律请求代理 URL → Bearer Token 转发给智谱 → SSE 流式响应原路返回。

AI 智能体方案

三层安全降级架构
第1层智谱 glm-4.5-air + 知识库 RAG— Cloudflare 代理，调用云端大模型+检索，结合内置 System Prompt 和项目页面动态上下文回答问题
第2层本地 FAQ 知识库 — 智谱/代理任一层失败时自动降级，基于关键词匹配 + 评分算法回答常见问题
项目上下文注入
用户提问时，前端会根据关键词匹配读取对应项目页 HTML，提取文本内容作为上下文传给智谱AI，使AI能回答项目页面中的详细信息。

访问统计方案

Vercount — 前台展示
在页面角落显示 PV/UV 数字，用于统计页面访客数量并做简单前端展示，初次访问自动同步历史数据。
百度统计 — 后台分析
负责详细流量分析（来源、受访页面、停留时长等）。通过虚拟页面（_trackPageview）方式记录访客在小助理中的提问内容，不断优化项目。

性能优化

  • 懒加载：所有非首屏图片添加 loading="lazy"，延迟加载减少首屏请求
  • 图片压缩：大图压缩至 605KB 以内，提高加载速度符
  • 异步加载：统计脚本使用 defer/async，不阻塞页面渲染
  • 响应式设计：CSS 媒体查询适配 PC/平板/手机，移动端单栏布局
